# Episodio 004 · Comparaciones

Graba en una sola toma. Empieza con 1 segundo de silencio y deja una pausa de 1 segundo (o algo más) entre bloque y bloque. Termina con 1 segundo de silencio.

1. A veces un programa tiene que decidir. Y para decidir, primero compara.

2. Tengo edad igual a veinte. Ahora le pregunto a Python: ¿edad es mayor o igual que dieciocho?

3. Python responde True, que significa verdadero.

4. Cuidado: para comprobar si dos valores son iguales se usan dos signos igual. Uno solo guarda, dos comparan.

5. Aquí la respuesta es False, falso, porque veinte no es dieciocho.

6. Verdadero o falso. Esa es la base para decidir. En el próximo vídeo, el if.
