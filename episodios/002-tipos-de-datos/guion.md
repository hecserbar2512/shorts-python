# Episodio 002 · Tipos de datos

Graba en una sola toma. Empieza con 1 segundo de silencio y deja una pausa de 1 segundo (o algo más) entre bloque y bloque. Termina con 1 segundo de silencio.

1. Ya sabemos guardar datos en variables. Pero no todos los datos son iguales. Python distingue varios tipos.

2. Un número entero, como veinticinco, es de tipo int.

3. Un texto, como Ana, va siempre entre comillas, y es de tipo str.

4. Para ver el tipo de cualquier dato, usa type. Python te lo dice.

5. Y con el texto, lo mismo: str. Las comillas son lo que lo distingue.

6. Número o texto: Python lo sabe. En el próximo vídeo, operaciones con números.
