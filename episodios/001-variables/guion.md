# Episodio 001 · Variables en Python

Graba en una sola toma. Empieza con 1 segundo de silencio y deja una pausa de 1 segundo
(o algo más) entre bloque y bloque. Dentro de cada bloque, habla seguido.

1. Casi todo en programación empieza con una idea: guardar datos. Y para eso existen las variables.

2. Una variable es un nombre que le pones a un dato para usarlo después. Como una caja con etiqueta: aquí, edad guarda el veinticinco.

3. Fíjate: el igual no significa igualdad. Significa guarda este valor con este nombre.

4. Ahora puedo usar la caja cuando quiera. Si pido a Python que muestre edad, me enseña lo que hay dentro.

5. Y el contenido se puede cambiar. Guardo un veintiséis, y la misma variable ahora vale otra cosa.

6. Un nombre, un valor. Así de simple. En el próximo vídeo, los tipos de datos.

Termina con 1 segundo de silencio.
