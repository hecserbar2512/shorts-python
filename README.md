# shorts-python

Canal de YouTube Shorts "Código de Bolsillo": conceptos básicos de programación en Python, en español de España.

## Estructura

- `episodios/NNN-nombre/ficha.json`: guion por bloques, código en pantalla, metadatos y estado del episodio.
- `episodios/NNN-nombre/ejemplo.py`: el código real que se muestra en el vídeo (se ejecuta para comprobar la salida).
- `episodios/NNN-nombre/guion.md`: texto limpio para grabar la voz.

## Reglas

- No se guardan contraseñas, claves ni credenciales en este repositorio.
- Cada código de ejemplo se ejecuta antes de publicar y su salida se comprueba.
